I've always found it easier to understand myself through words — books first, then journaling my own thoughts and realities. Writing has always been how I process things and my life. Lately, I've started learning to code, and I realized this could be another way to write: instead of pages, I'm building a page. This site is where that learning lives.

I know learning can be hard but I have always loved the feeling which comes with being smart enough to learn it all. Nowadays, I can feel stuck but if you would not know the feeling of being stuck you can never crave the freedom. So yeah, here is to always learning.

Projects

Samrakshini — Women's Safety App

React.js · Node.js · MongoDB

A women's safety web app for real-time location tracking, letting users share their live location with trusted contacts during emergencies. Built with React.js on the front end and a Node.js/Express backend, with MongoDB storing user and location data. Focused on a fast, simple UI so location sharing can be triggered within seconds.

GitHub

SoulCloset+ — AI Fashion & Sustainability Assistant

React.js · Node.js · MongoDB

An AI-powered virtual wardrobe app — upload clothing photos and it auto-detects type, color, and fabric to build a digital closet. Includes a mood-based outfit recommendation engine using color psychology, weather, and personal aesthetic, plus a concept called "AuraSwap" for aesthetic-based clothing swaps to promote sustainable fashion. Pitched at a college-level Ideathon.
